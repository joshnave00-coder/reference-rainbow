Using Scriptorium

What this is

A reading room over one DuckDB file, bible.duckdb: 144 texts in 60 languages, every Hebrew, Aramaic and Greek word tagged with Strong's numbers, Strong's dictionaries, 344,756 cross-references, red letters, repeated phrases, and who wrote each book when and where. Everything is read-only here; rebuild with python build.py.

Read

Type a passage, add translations with “+ Translation”, and turn on Interlinear to see the original words. Click any original word for its Strong's entry. Red marks words of Jesus; dark red marks words of God detected from quotations.

Strong's

Search by number, English meaning, transliteration or the Hebrew/Greek word. Each entry shows Strong's definition, modern glosses, how the KJV, WEB and BSB translate it, where it occurs by book, and verses.

Books & dating

A timeline of traditional (dark) and critical (blue) date ranges. Open a book for each view's author, date, place, who holds it and its sources.

Translations

Coverage, verse numbering system and licence for each text. Switch to the eBible.org catalogue to see what else exists. “Read” adds a translation to the Read view.

Tables

Each table's description and column documentation come from the database itself. Filter any column by “contains”, “equals” or “starts with”.

SQL

Start from an example query. The console cannot change the database or read other files.

Starting, stopping and updating

Scriptorium runs while its black window is open; close that window to stop it. To start it again, double-click Start Scriptorium in the project folder. Data & setup has the details, your database's status, and buttons to update the data or make a copy you can share.
